# Inactive branding source assets

These files preserve alternate Rasheed Systems branding without changing active public assets.

- `alternate-logo-mark-512.png` is the canonical byte-preserved copy for the identical external files `D:\R2\logo-mark-512.png` and `D:\R2\favicon-512.png`.
- `alternate-og-image.png` is the canonical byte-preserved copy of `D:\R2\og-image.png`.

The active files in `public/` and `app/icon.png` are intentionally unchanged.
